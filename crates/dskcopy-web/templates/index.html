Features

Everything you need. Nothing you don't.

dskcopy focuses on one job — writing disk images to removable drives — and gets out of your way.

⚡

Streaming writes

Decompresses GZ, XZ, ZIP, BZ2 on the fly. No need to extract first.

🛡

Safe by default

Lists only removable drives. System volumes are hidden unless explicitly requested.

✅

Verified writes

Byte-by-byte or SHA-256 verification after flashing, so you know it landed clean.

🪟

Windows ISOs

Dual-partition Windows install media with optional autounattend bypass for TPM/Secure Boot.

🍎

macOS installers

Handles DMG installers via createinstallmedia for bootable macOS USBs.

🧪

Fake flash detection

Built-in bad-block scan catches counterfeit USBs that misreport capacity.

CLI

Scriptable. Predictable.

Every GUI action is available on the command line — perfect for CI, automation, and remote provisioning.

~/iso 
# list detected removable drives
$ dskcopy-cli list-drives

# flash an image to a target drive with byte-by-byte verify
$ dskcopy-cli flash ./ubuntu-24.04.iso /dev/disk4

# flash an HTTPS URL directly, no manual download
$ dskcopy-cli flash https://releases.ubuntu.com/24.04/ubuntu-24.04-desktop-amd64.iso /dev/disk4

# write the same image to multiple USBs in parallel
$ dskcopy-cli flash ./image.img /dev/disk2 /dev/disk3 /dev/disk4

# scan a drive for bad sectors / fake-flash capacity
$ dskcopy-cli check /dev/disk4 --quick
