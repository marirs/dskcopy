Why dskcopy

Everything you need. Nothing you don’t.

Cross-Platform

Native on Windows, Linux and macOS. No runtime dependencies, no Electron, no bloat.

Single Binary

Download and run. Assets are embedded at compile time — one file, zero setup.

Blazing Fast

Rust core with optimized block I/O pushes your USB to its hardware ceiling.

Verified Writes

Bit-for-bit verification after every flash. Know your bootable media is perfect.

CLI & GUI

Full-featured command-line mode for scripts and CI, plus a clean GUI for humans.

Broad Format Support

ISO, DMG, IMG. Transparently decompresses .gz, .xz and .zst archives on the fly.

Flash from URL

Point dskcopy at a download URL. It streams directly to disk — no temp file required.

Safe Drive Detection

Smart heuristics filter out system disks. Accidental OS overwrites are virtually impossible.

How it works

Three steps. Done.

01

Select Source

Choose a local ISO/IMG/DMG file — or paste a URL to flash directly from the web.

02

Select Drive

Pick your USB target. System drives are hidden by default — no guard-rails to bypass.

03

Flash

Hit flash. dskcopy unmounts, writes block-by-block and verifies. You reboot. It works.
