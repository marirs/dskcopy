# dskcopy Web

This is the landing page and download portal for **dskcopy**, a blazing fast cross-platform USB bootable media tool.

## Tech Stack
- **Backend:** Rust, Axum, Tokio
- **Frontend:** HTML, CSS, minimal JS, Tera Templates
- **Deployment:** Single binary (assets embedded with `rust-embed`)

## How to run

```bash
cargo run
```

Then visit `http://localhost:3000` in your browser.

## Features
- Fully responsive dark-mode design
- Single binary deployment
- Zero external CDN dependencies
- CSS-only and minimal-JS animations
